## 花了多少 AI 算力

Cursor 的對話紀錄只記下每一步做了什麼，**沒有記 token 數**，所以下面是從紀錄**推算**的，不是帳單上的數字。
把主對話和 2 個 AI 助手的紀錄（約 1,535 次模型呼叫，全部是 Claude Opus 5.5）加總，照 Anthropic API 牌價換算：

| 類型 | Token 數（估算） | 每百萬 token | 美金 | 新台幣 |
|---|---:|---:|---:|---:|
| 讀取快取（重讀前面的內容） | 約 633,800,000 | $0.20 | $126.76 | 約 4,121 |
| 寫入快取（5 分鐘） | 約 14,520,000 | $5.00 | $72.58 | 約 2,359 |
| 輸出（含思考） | 約 600,000 | $20.00 | $12.07 | 約 392 |
| **合計** | **約 6.49 億** | | **約 $211** | **約 6,900** |

- 主對話約 $207，2 個 AI 助手約 $4（施政研究約 $1、新聞特輯素材研究約 $3）。
- AI 每做一步都要重讀前面的內容，所以幾乎都是「讀取快取」，單價只有一般輸入的二十分之一。如果沒有快取，同樣的工作量約 US$2,605（約新台幣 8.5 萬元），快取省了約 92%。
- 「寫入快取」比例偏高，是因為中間有 30 次停超過 5 分鐘（等 dAAAb 看成果、睡覺、處理帳單），快取過期後整段內容要重新寫入。
- 這是照 API 牌價算的**等值金額**；實際支付以 Cursor 帳單為準。網站放在 GitHub Pages（免費），資料庫用 dAAAb 既有的 Supabase 付費專案，Google Analytics 免費，網域 encore.taipei（Gandi）另計。
- 匯率以中央銀行 2026/10/22 新臺幣對美元銀行間收盤匯率 32.508 計算（寫這份紀錄時最新公布的一筆）。

### 怎麼估的

1. 紀錄裡每一段 AI 回覆、每一次操作和結果都有原文。字數換成 token：中文字約 1.2 token／字，英文與程式約 2.6 字元／token（Claude Opus 5.5 的新斷詞器），每張截圖約 1,600 token；改檔只記了結果，用改動內容估輸出量。
2. 每次模型呼叫都會重讀前面所有內容。和上一次相同的部分算「讀取快取」，新增的部分算「寫入快取」，前後隔超過 5 分鐘就當作快取過期、整段重寫。
3. 10/23 晚上做 README 時，對話超過模型的 100 萬 token 上限，系統自動做了一次摘要。用這個點校正換算比例：照上面的字數規則算會多估約四成，所以全部乘上 0.72。
4. 對照：網站「製作花絮」彩蛋裡，前 138 分鐘當時用另一種方法估出 320 次呼叫、4,510 萬 token、US$14.9；用這次的方法算同一段是 313 次、約 5,400 萬 token、約 US$16，兩者差約一成五。
5. 紀錄裡的「思考」可能只是摘要，實際輸出可能更多；整體數字可能差到兩、三成，請當成量級參考。

```text
加上 Cyberpunk 來生（Afterlife）的場景、光影、配色和風格
打造一個  2033 年的 3D 台北 來生 夜店，坐落在松機遷移後的 台北 AI 園區裡
非常未來風
在夜店裡，畫面鏡頭面對中央舞台，蔣萬安在台上
很多人影，萬頭鑽動，背對鏡頭看著舞台上的蔣萬安在尖叫，背景音樂播放「台北安可」
蔣萬安除了跳麥可傑克森的旋轉舞步搭配台北安可不斷輪播外
蔣萬安會一直不定時用 3D 對話泡泡說出他的政見，政見的字也都是 3D 的會從畫面外飛進來
底下群眾會一直說他喜歡哪個蔣萬安的政策 感謝蔣萬安做的哪些事。蔣萬安執政四年的政策成績資料可以從 gov.taipei 搜尋

```

附圖是兩張「黃金十年」競選文宣，只拿來參考政見內容，原圖已不放在 repo 裡。

## 人和 AI 怎麼分工

- **dAAAb**：提出點子（夜店、電視台、伴舞、大樓、上架頁）、看成果、指出問題（畫面閃黑、鏡頭穿幫、Safari 的 MV 不會自動播、870 公頃的用詞…）、做所有需要判斷的決定（買網域、開 GitHub repo 與 Pages、開 Google Analytics、網址要不要從 `/beta` 改成 `/tv`、用詞），以及審核市民投稿。
- **AI**：查證施政成績與政見並逐條附出處（`src/data/`），寫所有程式與 3D 場景，做分享圖和 README 的截圖動圖，設定 GitHub Actions 部署、Supabase 資料表與函式、Edge Functions 和 Google Analytics；做開源授權、資安、台灣用語與簡體字檢查，再依結果修正。
- 內容都依據公開資料整理；網站各處都註明「粉絲創作之互動藝術作品，非蔣萬安競選團隊官方網站」。素材來源與授權見 [CREDITS.md](../CREDITS.md)。
